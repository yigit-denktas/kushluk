# ADR 0003 — Front is Today, back is For You

**Status:** Accepted

## Decision

The default duplex grammar is:
- Front: **Today** — practical orientation.
- Back: **For You** — personal/editorial material.

This is a compositional rule, not a rigid requirement that every category always appears.

## Rationale

The physical sheet should answer immediate practical needs first, then reward deeper reading.

## Consequences

Templates and editorial allocation should preserve this distinction while allowing reflow.
