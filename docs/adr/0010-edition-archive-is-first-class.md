# ADR 0010 — Edition archive is first-class

**Status:** Accepted

## Decision

Each edition and canonical story receives stable identity and is archived in a form suitable for search, retrieval, and cross-edition references.

Canonical content is Markdown plus structured metadata; HTML/PDF are derived artefacts.

## Rationale

The newspaper should develop memory. Later stories should be able to say “we covered this two months ago” without relying on an opaque chat history.

## Consequences

Archive/search/RAG compatibility is part of the core model, not an afterthought.
