# Architecture Decision Records

ADRs preserve decisions that future maintainers or agents must not silently reinterpret.

Status values:
- Proposed
- Accepted
- Superseded
- Rejected

Each ADR contains:
- Context
- Decision
- Rationale
- Consequences
- Alternatives
- Revisit conditions
